2.1.10 integration (2026-10-01): merging the inline question and approval cards (C-27.1, C-27.2) with approvals within reach (C-27.5). Views carry the provider's request id under both names; C-27.1 permits only an exact join. A view from a daemon older than both fields gets an independent card keyed by immutable approval id, so stale question drafts cannot answer a replacement request. The strip's Review brings a pending question into view, where its card is the form, and opens the request sheet only for a tool request.
