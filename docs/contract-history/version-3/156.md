C-23.31: a lane run is recognised by the `entrypoint` Claude Code stamps on its transcript entries, not by `promptSource` (2026-10-03). The desktop app now sends its prompts as `promptSource: sdk`, so v1's rule (one or two `sdk` prompts) read desktop sessions that one or two messages started as lane runs: 5,884 of one machine's 8,202 desktop and terminal sessions, 19 of them holding pending notices, were left out of `sessions` listings, nudges, cold revives and handoff. The same rule read 3,238 `claude -p` runs (probes, one-shots, resumed lanes) as sessions. The prompt rule now reads only prompts that name no entrypoint.
