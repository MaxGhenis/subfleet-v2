C-11.1, C-11.2 (2026-10-09, tier preferences): each task chain has one entry per tier, either a short model name or a non-empty list of distinct current model names in preference order. Routing flattens only the entries from the job's tier upward, removes duplicates keeping the first occurrence, and tries each model in order. Within a tier, a later model is tried only when no lane of an earlier model admits the job; order across tiers is unchanged. `fallback: upward-only` still excludes entries below the job's tier. Existing string-only policies retain their routing behavior; the shipped default chains are unchanged.
