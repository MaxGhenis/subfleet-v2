Saturation is fixed for the remainder of a pass. On the next pass the daemon rebuilds the rolling count from the ledger. This gives the highest-ranked eligible job its first choice among lanes with budget left and lets it try alternatives before the next job. With a global limit of three, the new test starts the same first three jobs as the unlimited control, across session/background classes, tiers and FIFO. For lane limits, a candidate whose only lane is saturated can wait while a disjoint pinned job proceeds.

## Limits and decisions

The budgets bound reservations of non-exempt jobs. Attended or priority bursts, uncharged probes, and launches replayed from an already committed reservation can still occur. A replay uses its original `reserved_at` in the rolling count. Counts reflect the surviving store ledger and the current policy's priority ancestry. Terminal rows count while retained. The lane scope is the recorded lane ID. A start that expires during a long pass can be used from the next pass, subject to the existing admission checks. Where the existing guards, leases, backoff or FIFO already hold a job, that reason can take precedence.

C-11.1 includes the exact file digest in every decision. The first implementation declared the keys in `subfleet/default_policy.json`, and the broad unit run caught the resulting change in `test_shipped_policy_preserves_raw_hash_and_disabled_ramp_defaults`. I restored the shipped file bytes and kept the defaults in the admission settings, following the C-6.18 ramp precedent. This preserves the shipped SHA-256 `64d90a926787d41a866c979f33dc98c081b5c2e2ec787115118429a4504b14b4`. The default-behavior test verifies the fixture policy's actual base digest and compares the rest of the stored decision bytes against the captured base fingerprint at a fixed clock.

The scheduling interpretation was whether a budget-only waiter should keep a physical in-flight slot elsewhere. It releases that claim because its saturated lane cannot reopen in the current pass. A wait that also encounters a physical slot refusal follows the existing waiter rules.
