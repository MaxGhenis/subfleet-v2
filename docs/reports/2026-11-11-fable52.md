## Fix round 1

Model-scoped weekly bucket defaults now follow the loaded policy. Each family takes the first Claude model named for it by short name or scope, then the first Claude id with that family, then the family's shipped fallback. The resolver preserves the policy id verbatim. The stream helper compares families case-sensitively and uses the attempt's own id with one trailing `[1m]` removed when the family matches. The daemon supplies the map to usage reads, probe and detached classification, and turn classification. Adopted attempts use the same adapter path with their existing launch notes. [Adapter](../../subfleet/adapters/claude.py), [daemon](../../subfleet/daemon.py), [turn service](../../subfleet/conversations/service.py)

- The stream cases cover L1 and L2 with and without a Fable reserve, with Fable's own event as a control. The L2 Sonnet case checks that another model's full Sonnet row is scoped to `claude-sonnet-5-5` and blocks Sonnet with `below-floor`. [Stream and scheduler tests](../../tests/unit/test_scoped_stream_capacity.py)
- The daemon cases cover the usage sensor, read-only Opus admission at standard and hard tiers, and turn readings and closures. The original head had 18 assertion failures and four passing controls. All 22 cases passed after the fix. [Daemon tests](../../tests/fake/test_reserve_authorization.py)
- Resolver tests cover precedence, policy order, missing families and the shipped policy. The helper tests draw family maps and check an opaque default id. Invariant 3 applies to the helper when the map's ids contain no `[`. The fallback equals the shipped ids, and loading the shipped policy resolves to that same map. [Resolver and helper tests](../../tests/unit/test_scoped_window_scope.py)

R4, which compares lowercase families, failed `test_scoped_window_scope_examples` for `claude-Fable-5-1`. R5, which removes every `[1m]`, failed the same test for `claude-fable-5-1[1m][1m]`. Each run had 1 failure and 69 passes. The restored adapter matched its backup by SHA-256 after both runs.
