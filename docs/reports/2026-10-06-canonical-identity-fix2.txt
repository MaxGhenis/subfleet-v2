Rollback (also the text for the hub's PR body)
A rollback to 2.1.11 skips an in-flight output export when its remaining output
lease is canonical and differs from the exact key "out:" + the stored out_path,
because 2.1.11 looks up only that exact key. Case, Unicode-normalization, caseless
expansion and conservative equivalence changes can cause this mismatch. Jobs
with an exact legacy lease held by that job still export; already exported jobs
need no export. Drain in-flight output jobs on the new daemon before rollback.
