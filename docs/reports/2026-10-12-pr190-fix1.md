# PR #190 fix round 1

Base: `bccda8c17fa6`. Implementation commits: `960cb9776`, `72d41eb53`,
`9414d1c68`, and `2a621655c`. All work stays in the assigned workspace.

All three findings are fixed:

- **P2: bounded reads and linear PEM extraction.** The cap is **4 MiB**, well
  above ordinary system bundles of a few hundred KiB. `read_regular` reads at
  most the cap plus one byte to detect oversize. Forward-only searches extract
  nonoverlapping certificate blocks; an unmatched opening marker ends the scan.
  Oversized files add no variable and use the existing once-per-path warning.
- **P2: one selection per launch.** `_credential_environment` selects once;
  `assemble` merges those additions without validating again. Adapter inspection,
  guard preflight and guardian startup reuse that selection for ordinary
  launches, resumes, conversation turns and requested-model probes.
  Reconstruction through `_relaunch_env` selects against the current file again.
- **P3: doctor version environment.** The ordinary Codex version subprocess uses
  the selected state root's policy, falling back to shipped defaults before
  `policy.json` exists. Invalid policy is diagnosed before spawning. The Claude
  check continues to inherit its environment without an `env` argument.

The contract states the cap, linear extraction and one-selection rule. Existing
operator values (including empty values and both CA variables), at most one
Subfleet-added source, and unchanged Claude environments remain intact.
