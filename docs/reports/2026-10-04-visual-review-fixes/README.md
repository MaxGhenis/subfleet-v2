## Comparison with the PR base

The expected red regression runs above demonstrate the findings on the reviewed head; they are not failures of the fixed code. Source comparison with `b11f766b` classifies their origins:

- **Approval scope:** the base pending non-question card showed the complete request (`app/Sources/UIApprovals.swift:37`); the PR moved it behind Details and introduced the incomplete command projection. Base questions already omitted additional scope: the fix also closes that earlier correctness gap.
- **Outcomes:** the base always displayed `turn.statusText` (`app/Sources/UIWindow.swift:598`); the PR added the suppression. “Worked” group labels were introduced by the PR.
- **Serving facts:** the base person-turn status line called `ServedChipView` (`app/Sources/UIWindow.swift:602`). Hover-only ordinary/live/failed metadata is a PR regression. Receipt notice metadata was already absent in the base, and is covered by this fix too.
- **Sidebar:** the base used `NavigationSplitView` and `List(selection:)` (`app/Sources/UIWindow.swift:18`, `:173`) with a separate badge. The PR replaced them with button-based scrolling. The explicit list-focus shortcut additionally ensures keyboard reachability.
- **Tool detail:** the base showed the raw tool summary (`app/Sources/UIWindow.swift:1025`). The PR's new label projection lost its command/search/file details and misread heredoc input.
- **Send/amber:** the base used native Send styling and primary permission-picker text (`app/Sources/UIComposer.swift:230`). The PR introduced `QuietButtonStyle` and the amber composer label; its custom style omitted disabled state and its light amber lacked text contrast.
- **Filter:** the base had a visible segmented provider Picker (`app/Sources/UIWindow.swift:78`). The PR replaced it with an icon-only menu.
- **Snapshots:** the renderer was introduced in this PR, so its natural-scale assertion and incomplete fixture are PR defects. The current host's natural 1× capture initially passed; the controlled 2× test reproduces the Retina failure consistently.

One preliminary snapshot compile had **3 setup errors** because the shared filesystem ran out of space (`ld: write() failed, errno=28`). This is an environment failure independent of either source baseline, excluded from successful test/mutation counts. [Log](infrastructure-disk-full.log), [JUnit](infrastructure-disk-full.xml), and [owned-artifact cleanup](disk-cleanup.json) preserve it. The runner now releases its completed temporary raster/object files after each slice. Earlier probe-development errors (unavailable sandbox Vision services, coordinate/OCR assertions, or editing a compiler input during an early compile) were verification-harness issues; none is counted as a product failure or mutation kill.
