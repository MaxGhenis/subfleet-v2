# Visual pass: round-two fixes for #128

The approval card and sheet now bound the grant area, place scope before commands and bulk content, and keep the action row outside the scroll area. Codex progress labels come from the script inside the recorded shell wrapper. Question cards omit duplicate grant rows and retain locally submitted answers through event resets and replay within the same app session. Native object-valued input summaries retain unknown grants. Sidebar headings cannot be selected, and conversation rows use the native selection fill once.
