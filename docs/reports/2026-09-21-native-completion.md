# Native cutover completion

The remaining public operations now execute in v2. The compatibility fixture
replays every recorded v1 invocation and asserts that none delegates to v1.
Private `_record-run`, `_record-lane`, `_record-cooldown`, and `_tickle` callbacks
refuse with an actionable explanation; they cannot record a fabricated result
or revive an old worker. Public `tickle`, sessions, handoff, and gates remain
native operations.

`pick codex|claude` reads the current daemon evidence and preserves ownership,
identity, desktop exclusion, closure, freshness, reserve, and concurrency rules.
A bare pick cannot perform a supervised admission probe, so unmeasured or
probe-required capacity waits. Explicit models scope the recommendation;
without one, all policy models in the family must qualify. Picks are advisory
and do not reserve execution slots.

`errors` and `brief` read v2 state and report offline uncertainty. `watch`,
`keepalive`, and `reset codex` queue the existing timer workers with their
existing guards. Preview is read-only. Login prints manual authentication and
re-enrollment instructions. Re-enrollment preserves the old lane and limits,
requires an idle disabled binding, verifies the same account, and contains its
Claude validation turn through a durable guardian before releasing its lease.

The tracked Codex shim stops when pick or subscription validation fails, passes
explicit models to the picker, removes inherited API keys for noninteractive
work, and requires the original home for raw continuations. Interactive Codex
retains its behavior. The native PreToolUse guard replaces the old attached
runner hook; settings updates preserve unrelated hooks.

The installed Swift app includes account rows, reload feedback, running and
waiting jobs, recent results, and batch groups. It reads daemon snapshots.
Frontend model tests and the macOS CI build verify its data contract and
compilation. Native accessibility inspection timed out on this machine, so a
new visual pass is not claimed. The earlier user-guided check confirmed account
rows and reload feedback.

Final full-suite, CI, performance, and installation evidence is recorded with
the versioned release under `~/.local/share/subfleet/releases/` and its matching
`~/.subfleet/cutovers/` backup. The seven-day soak and 100-job canary were waived
by the direct-cutover decision; they are not passed checks.
